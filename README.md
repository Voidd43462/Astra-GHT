# Astra-GHT

Портфолио Дениса: сайты, боты, автоматизация и Minecraft/GameDev.

## Структура

- `index.html` — разметка страницы
- `styles.css` — дизайн-система (светлая и тёмная темы, bento-сетка)
- `script.js` — данные проектов, модальные окна, анимации, переключатель темы
- `api/studio/*` — серверная авторизация Studio (сохранена, на сайте пока не используется)
- `_old/` — прежняя версия фронтенда (Studio-редактор, GSAP, частицы)

Проекты и навыки редактируются в массивах `projects` и `craft` в начале `script.js`.

Проект рассчитан на Vercel (статика + serverless functions).

## Telegram и общий список работ

Работы хранятся в Neon Postgres (`/api/works`). Двусторонняя связка с каналом:

- **Telegram → сайт:** пост в канале с хэштегом `#работа` становится карточкой. Первая строка — название, вторая — кратко, остальное — описание; ссылки `https://…` — демо, остальные хэштеги — теги. Правка поста обновляет карточку.
- **Сайт → Telegram:** в Studio у работы включите «Синхронизировать с Telegram-каналом» и нажмите «Сохранить» — бот опубликует или обновит пост. Удаление работы в Studio удаляет пост.
- Удаление поста вручную в Telegram на сайт не передаётся (Telegram не присылает такое событие) — удаляйте работу в Studio.

Переменные окружения Vercel: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL` (`@username` или id), `TELEGRAM_WEBHOOK_SECRET` (любая случайная строка). После деплоя войдите в Studio и один раз откройте `/api/telegram` — вебхук зарегистрируется.

# Astra-GHT

**Astra-GHT — Advanced Software, Technology & Research**

Персональное портфолио Дениса: web-разработка, автоматизация, Discord/Telegram-боты и Minecraft/GameDev.

## Возможности

- адаптивный тёмный интерфейс;
- GSAP/ScrollTrigger-анимации;
- Canvas-поле частиц;
- интерактивные карточки проектов;
- просмотр web-проектов прямо на сайте;
- галерея и структурированное описание для программ, ботов и модов;
- Astra Studio с серверной авторизацией;
- полноценный чат посетитель ↔ владелец без перехода в Telegram;
- хранение диалогов в PostgreSQL;
- автоматическое обновление сообщений в открытом диалоге;
- входящие диалоги и ответы владельца из Astra Studio.

## Astra Studio

Открывается кнопкой `Studio` или через `Ctrl + Shift + A`.

Studio позволяет редактировать содержимое портфолио, карточки проектов и управлять входящими чатами. Данные интерфейса Studio сохраняются локально в браузере; сообщения чата хранятся на сервере в базе данных.

### Защита Studio

Studio закрыта серверной авторизацией:

- `/api/studio/login` — проверка пароля и выдача подписанной сессии;
- `/api/studio/session` — проверка текущей сессии;
- `/api/studio/logout` — завершение сессии.

Переменные окружения:

```text
STUDIO_PASSWORD=<твой пароль>
STUDIO_SECRET=<случайная строка>
DATABASE_URL=<строка подключения Neon PostgreSQL>
```

### Чат

Чат использует PostgreSQL через пакет `@neondatabase/serverless`. Таблицы создаются API автоматически при первом запросе.

Посетителю не требуется аккаунт: браузер получает защищённую сессионную cookie, по которой определяется его диалог. Владелец открывает `Studio → Чаты`, видит список обращений и отвечает прямо из панели.

Сообщения обновляются автоматически примерно каждые 2.5 секунды. Для настоящего двустороннего push-режима можно заменить polling на WebSocket без изменения модели хранения.

## Запуск

Проект рассчитан на Vercel и Node.js serverless functions.

Перед первым использованием чата подключите к проекту Neon PostgreSQL и добавьте `DATABASE_URL` в переменные окружения Vercel. Пакет `@neondatabase/serverless` используется для serverless-доступа к PostgreSQL. citeturn239750search0

## Структура

- `index.html` — структура портфолио, контактный блок и Studio
- `styles.css` — основная визуальная система
- `visual-editor.css` — Studio и проектный UI
- `script.js` — анимации, Canvas и Studio-редактор
- `studio-auth.js` — клиентская авторизация Studio
- `chat.js` — посетительский чат и Inbox Studio
- `chat.css` — стили чата
- `api/chat.js` — API диалогов и сообщений
- `api/studio/login.js` — серверный вход
- `api/studio/session.js` — проверка сессии
- `api/studio/logout.js` — выход
- `package.json` — зависимости serverless backend

# Astra-GHT

Портфолио Дениса: сайты, боты, автоматизация и Minecraft/GameDev.

## Структура

- `index.html` — разметка страницы
- `styles.css` — дизайн-система (светлая и тёмная темы, bento-сетка)
- `script.js` — данные проектов, модальные окна, анимации, переключатель темы
- `api/studio/*` — серверная авторизация Studio (сохранена, на сайте пока не используется)
- `_old/` — прежняя версия фронтенда (Studio-редактор, GSAP, частицы)

Проекты и навыки редактируются в массивах `projects` и `craft` в начале `script.js`.

Проект рассчитан на Vercel (статика + serverless functions).

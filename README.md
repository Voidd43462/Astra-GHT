# Astra-GHT

**Astra-GHT — Advanced Software, Technology & Research**

Персональное портфолио Дениса: web-разработка, автоматизация, Discord/Telegram-боты и Minecraft/GameDev.

## Что внутри

- кинематографичная motion-система на GSAP;
- инерционный скролл на Lenis;
- собственное Canvas-поле частиц и связей;
- адаптивная вёрстка и reduced-motion режим;
- анимированная орбитальная сцена Astra;
- встроенная **Astra Studio** для управления содержимым сайта;
- серверная авторизация Studio через `HttpOnly`-сессию;
- ограничение неудачных попыток входа на стороне API.

## Astra Studio

Открывается кнопкой `Studio` в шапке или сочетанием `Ctrl + Shift + A`.

Панель позволяет менять без редактирования HTML:

- заголовок и описание первого экрана;
- текст блока «Обо мне»;
- названия и описания проектов;
- стек технологий;
- цвет акцента;
- интенсивность анимаций;
- видимость орбитальной сцены.

Локальные настройки интерфейса сохраняются в `localStorage`. Есть импорт и экспорт JSON.

### Защита Studio

Панель больше не открывается напрямую. Перед входом браузер обращается к серверным endpoint'ам:

- `/api/studio/login` — проверка пароля и выдача подписанной сессии;
- `/api/studio/session` — проверка текущей сессии;
- `/api/studio/logout` — завершение сессии.

Пароль администратора **не хранится в HTML или JavaScript**. Для деплоя на Vercel задай в Project Settings → Environment Variables:

```text
STUDIO_PASSWORD=<длинный уникальный пароль>
STUDIO_SECRET=<случайная строка минимум 32 символа>
```

Оба значения должны быть секретами окружения и не должны добавляться в репозиторий.

Сессия использует `HttpOnly`, `Secure` и `SameSite=Strict` cookie с ограниченным временем жизни. После пяти неверных попыток API временно блокирует дальнейшие попытки с этого адреса.

### Важное ограничение

Текущая Studio — защищённый редактор локального содержимого браузера. Авторизация уже серверная, но кнопка «Сохранить» пока не публикует изменения обратно в GitHub автоматически. Для полноценной удалённой CMS потребуется отдельный слой хранения/публикации.

## Запуск локально

Открой `index.html` в браузере или запусти любой статический HTTP-сервер.

Для проверки серверной авторизации нужен хостинг/локальный runtime, который выполняет Node.js serverless functions из `api/`.

## Структура

- `index.html` — разметка, секции и Studio-панель
- `styles.css` — основная визуальная система и motion-стили
- `styles-refine.css` — уплотнение сетки и отступов
- `script.js` — анимации, Canvas и Studio-логика
- `studio-auth.js` — клиентский вход/выход и блокировка панели до серверной проверки
- `studio-auth.css` — окно авторизации
- `api/studio/login.js` — серверный вход
- `api/studio/session.js` — проверка сессии
- `api/studio/logout.js` — выход

## Публикация

Проект подходит для Vercel и других платформ, поддерживающих Node.js serverless functions. Для GitHub Pages/обычного статического хостинга серверные endpoint'ы из `api/` работать не будут.

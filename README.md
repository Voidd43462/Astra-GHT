# Astra-GHT

**Astra-GHT — Advanced Software, Technology & Research**

Персональное портфолио Дениса: web-разработка, автоматизация, Discord/Telegram-боты и Minecraft/GameDev.

## Что внутри

- новая адаптивная сетка без лишних вертикальных пустот;
- компактный sticky header без смещения по оси X;
- GSAP и ScrollTrigger для появления и scroll-анимаций;
- собственное Canvas-поле частиц без слежения за мышью;
- орбитальная сцена Astra с автономной анимацией;
- карточки проектов, блок навыков, «Обо мне» и контактный блок;
- адаптация под мобильные устройства и reduced-motion режим;
- встроенная Astra Studio с серверной авторизацией.

## Astra Studio

Открывается кнопкой `Studio` или через `Ctrl + Shift + A`.

Панель позволяет менять:

- заголовок и описание первого экрана;
- текст блока «Обо мне»;
- названия и описания проектов;
- цвет акцента;
- интенсивность motion;
- видимость орбитальной графики;
- импорт и экспорт JSON-конфигурации.

Настройки контента сохраняются локально в браузере. Публикация изменений непосредственно в GitHub пока не подключена.

### Защита Studio

Studio закрыта серверной авторизацией:

- `/api/studio/login` — проверка пароля и выдача подписанной сессии;
- `/api/studio/session` — проверка текущей сессии;
- `/api/studio/logout` — завершение сессии.

Пароль не хранится в HTML или JavaScript. На Vercel используются переменные окружения:

```text
STUDIO_PASSWORD=<твой пароль>
STUDIO_SECRET=<случайная строка>
```

Сессия хранится в `HttpOnly`, `Secure`, `SameSite=Strict` cookie сроком до 10 лет. После пяти неверных попыток API временно блокирует дальнейшие попытки с этого адреса.

## Запуск

Проект рассчитан на Vercel или другую платформу, которая поддерживает Node.js serverless functions из `api/`.

## Структура

- `index.html` — структура портфолио и Studio
- `styles.css` — единая визуальная система, адаптивная сетка и Studio UI
- `script.js` — анимации, Canvas и Studio-логика
- `studio-auth.js` — клиентская проверка сессии и вход
- `studio-auth.css` — окно авторизации
- `api/studio/login.js` — серверный вход
- `api/studio/session.js` — проверка сессии
- `api/studio/logout.js` — выход

Старая система CSS-надстроек в новой версии не используется.

# Astra-GHT

Персональное портфолио Дениса: web-разработка, AI, автоматизация, Discord/Telegram-боты и Minecraft/GameDev.

## Запуск локально

Открой `index.html` в браузере или запусти любой статический HTTP-сервер.

## Структура

- `index.html` — разметка и контент
- `styles.css` — визуальная часть
- `script.js` — интерактив и анимации

## Публикация

Проект подходит для GitHub Pages, Netlify, Vercel и любого статического хостинга.

# Astra-GHT

**Astra-GHT — Advanced Software, Technology & Research**

Персональное портфолио Дениса: web-разработка, автоматизация, Discord/Telegram-боты и Minecraft/GameDev.

## Что внутри

- чистая адаптивная сетка без лишних вертикальных пустот;
- компактный фиксированный header;
- GSAP-анимации появления и ScrollTrigger для секций;
- Lenis для плавного прокручивания;
- собственное Canvas-поле частиц без реакции на положение мыши;
- интерактивная орбитальная сцена Astra;
- адаптация под мобильные устройства и reduced-motion режим;
- встроенная Astra Studio с серверной авторизацией.

## Astra Studio

Открывается кнопкой `Studio` в шапке или сочетанием `Ctrl + Shift + A`.

Панель позволяет менять:

- заголовок и описание первого экрана;
- текст блока «Обо мне»;
- названия и описания проектов;
- цвет акцента;
- интенсивность motion;
- видимость орбитальной графики;
- импорт и экспорт JSON-конфигурации.

Настройки контента сохраняются локально в браузере. Публикация этих изменений в GitHub автоматически пока не подключена.

### Защита Studio

Studio закрыта серверной авторизацией:

- `/api/studio/login` — проверка пароля и выдача подписанной сессии;
- `/api/studio/session` — проверка текущей сессии;
- `/api/studio/logout` — завершение сессии.

Пароль не хранится в HTML или JavaScript. На Vercel задай в Project Settings → Environment Variables:

```text
STUDIO_PASSWORD=<твой пароль>
STUDIO_SECRET=<случайная строка>
```

Оба значения должны быть секретами окружения и не должны попадать в репозиторий.

Сессия хранится в `HttpOnly`, `Secure`, `SameSite=Strict` cookie. Срок действия текущей сессии — 10 лет; выход из Studio или очистка cookies потребуют нового входа. После пяти неверных попыток API временно блокирует дальнейшие попытки с этого адреса.

## Запуск

Проект рассчитан на Vercel или другую платформу, которая выполняет Node.js serverless functions из `api/`.

## Структура

- `index.html` — чистая структура портфолио и Studio
- `styles.css` — единая визуальная система и адаптивная сетка
- `script.js` — motion, Canvas и Studio-логика
- `studio-auth.js` — клиентская проверка сессии и вход
- `studio-auth.css` — окно авторизации
- `api/studio/login.js` — серверный вход
- `api/studio/session.js` — проверка сессии
- `api/studio/logout.js` — выход

Старая система CSS-оверрайдов удалена, чтобы исключить конфликты стилей.
